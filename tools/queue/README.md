# 초안 대기열 — **임시 폴더다**

`ANTHROPIC_API_KEY` 가 막혀 있는 동안만 쓴다. 캡처를 앱에서 바로 넣는
것이 본래 길이고 (`/add`), 키가 돌아오면 **이 폴더와
`tools/add_recipe.py` 를 같이 지운다.**

사람이(또는 Claude 가) 캡처를 읽어 초안을 여기 적어두면, 도구가
`/api/ingest/commit` 에 넘긴다 — 사전 대조·중복 방지·장보기 합산은
전부 서버가 한다.

```bash
APP_API_TOKEN=... python3 tools/add_recipe.py tools/queue/*.json
```

- 올린 파일은 지워도 된다. 레시피는 DB 에 있고 여기는 보내기 전의 쪽지다
- `bucket`·`label` 은 대충 적어도 된다. 서버가 사전을 다시 보고 제 값을 넣는다
- **원본 캡처는 안 남는다.** 이 경로는 저장만 하는 문이라 재파싱할
  원본이 없다 (원칙 ⑤ 가 지켜지지 않는 유일한 자리라 임시인 것이다)
