# 폰에 앱이 올라갔다 (2026-09-19)

**오늘 처음으로 `native/` 3,864줄이 진짜 폰에서 돌았다.** 그전까지 이 코드는
CI 에서 타입 검사와 번들만 통과했을 뿐 **한 번도 실행된 적이 없었다.**

이 문서는 그날의 기록이다. 절차는 [`deploy.md`](deploy.md) 6장에 있고,
여기에는 **무엇이 막혔고 왜 그랬는지**를 적는다 — 다음에 같은 자리에서
멈추지 않으려고.


나온 링크를 **폰 크롬으로** 열어 APK 를 받는다.

## 2. 막혔던 자리 — 순서대로

### ① Expo Go 로 갔다가 하루를 태웠다

"빌드가 없어서 빠르다" 는 이유로 골랐다. 폰에는 **"Something went wrong"
한 장**만 떴고 **원인이 한 글자도 없었다.**

좁히려고 잰 것이 **전부 정상이었다**:

| 잰 것 | 결과 |
|---|---|
| 배포 번들 (`expo export`) | 정상 (2.8MB) |
| **개발 번들** (`expo-router/entry.bundle`) | **HTTP 200, 6.4MB** |
| 매니페스트 | 200, `exposdk:57.0.0` |
| 꾸러미 버전 (`expo-doctor`) | 8개가 어긋나 있어 맞춤 |
| **앱을 실제로 실행** (`--web` + 브라우저) | **런타임 오류 0건, 화면 그려짐** |
| 폰의 Expo Go SDK | 57 (맞음) |

전부 정상인데 폰에서만 죽었다. `--tunnel` 은 `@expo/ngrok` 전역 설치에
실패해 켜자마자 죽었다.

**쓰는 사람이 말했다: "Expo Go 로 할 때마다 제대로 동작을 안 하는데 굳이
왜 하는지 모르겠어."** 맞는 말이었다 — **목표는 폰에 앱을 올리는 것이지
Expo Go 를 돌리는 게 아니었다.** EAS 빌드로 옮기고 나서 한 번에 됐다.

**교훈: 수단이 세 번 막히면 수단을 의심해라.** 그 세 번을 합치면 목표를
다른 길로 가는 것보다 이미 비싸다.

### ② `eas.json` 에 내가 심어둔 지뢰 둘

빌드를 돌리기 전에 발견해서 뺐다. 안 뺐으면 둘 다 **20분 뒤에** 나타났다.

- **`channel`** (세 프로필 전부) — EAS Update 값인데 `expo-updates` 가
  없었다. (실제로 EAS 가 빌드 중에 이걸 잡아내고 `expo-updates` 를 깐 뒤
  "Command must be re-run" 으로 멈췄다 — **실패가 아니라 다시 치라는 뜻**)
- **`developmentClient: true`** — `expo-dev-client` 없이는 못 돈다. 넣었다

### ③ `eas env:create` 는 deprecated

`eas env:set` 이다. 그리고 **`--environment` 를 빠뜨리면 안 된다** —
변수는 환경마다 따로 저장되고 빌드는 자기 프로필 환경 것만 읽는다.

`eas.json` 의 세 프로필에 `environment` 를 **명시**해뒀다. eas-cli 가 안
적어도 알아서 고르지만(`store`→production, `developmentClient`→development,
나머지→preview) 그건 **우연히 맞아떨어지는 것**이라 규칙으로 박았다.

### ④ 날 뻔한 사고 — `EXPO_PUBLIC_API_TOKEN` 자리에 Anthropic 키

`sk-ant-...` 를 넣는 명령을 쳤다. `eas` 가 설치돼 있지 않아 저장은 안 됐다.

**그대로 빌드됐으면 APK 를 뜯는 누구나 그 키로 요금을 태울 수 있었다** —
`EXPO_PUBLIC_` 은 번들에 **그대로 박힌다.** 키는 폐기하고 새로 발급했고,
CI 가 번들에서 `sk-ant-` 와 `SUPABASE_SERVICE_ROLE` 을 찾으면 막게 했다.

### ⑤ 401 의 진짜 원인 — 토큰을 두 번 만들었다

```
openssl rand -base64 32 | tr -d '\n' > ~/apptoken.txt
pbcopy < ~/apptoken.txt      # 값 A -> Vercel
openssl rand -base64 32      # 값 B (새로 생성!)
... env:set --value 'B'      # 값 B -> 앱
```

**Vercel 에 A, 앱에 B.** 그래서 401 이었다.

`openssl` 을 **한 번만** 치고 그 파일을 양쪽에 쓴다:

```bash
openssl rand -base64 32 | tr -d '\n' > ~/t.txt
pbcopy < ~/t.txt                      # Vercel 에 ⌘V, 저장, 재배포
npx eas-cli@latest env:set --environment preview --visibility sensitive \
  --name EXPO_PUBLIC_API_TOKEN --value "$(cat ~/t.txt)"
rm ~/t.txt
```

`"$(cat ...)"` 이 핵심이다 — **손으로 옮기지 않으니** 오타도 공백도 안 낀다.

## 3. 오류 메시지로 원인을 가른다

앱 화면의 글자가 그대로 진단이다. 이건 우연이 아니라 그렇게 만든 것이다
(원칙 ③ — "그냥 안 됐어요" 말고 다음 걸음을 말한다).

| 앱 화면 | 어디가 문제인가 |
|---|---|
| **"서버 주소가 아직 안 적혀 있어요"** | `EXPO_PUBLIC_API_URL` 이 빌드에 안 실렸다 |
| **"API 가 아직 안 열렸어요"** (503) | **서버** 의 `APP_API_TOKEN` 이 없거나 24자 미만. Production 체크와 **재배포**를 본다 |
| **"토큰이 안 맞아요"** (401) | 서버는 열렸는데 **두 값이 다르다.** 503 이 아니라 401 이면 서버 쪽은 이미 된 것이다 |
| **"앱이 멈췄어요"** + 스택 | `_layout.tsx` 의 `ErrorBoundary`. 거기 적힌 메시지가 답이다 |
| Expo Go 의 파란 **"Something went wrong"** | 우리 화면이 아니다. 모듈이 읽히다 터진 것이거나 Expo Go 경로다 |

**503 과 401 의 차이가 제일 쓸모 있다** — 어느 쪽 값을 고쳐야 하는지가 갈린다.

## 4. 폰에서 해볼 것

순서대로 하면 한 바퀴다. 안 되는 게 있으면 **어느 줄에서 멈췄는지**를 적어두면
고칠 자리가 바로 나온다.

### 식단

- [ ] 열면 **오늘부터** 보이나 (맨 위 지난 월요일이 아니라)
- [ ] 열나흘이 세로로 늘어서 있나
- [ ] 날짜에 **한 줄 메모**를 적고 지울 수 있나
- [ ] 지난 날에 **"만들었어요?"** 를 물어보나 (자동 체크되면 안 된다)
- [ ] 펼친 재료의 체크가 **잠겨 있나** (식단에서는 읽기 전용)

### 메뉴 고르기

- [ ] 검색이 **요리명과 재료** 둘 다 훑나
- [ ] 필터 셋(전체·안 만들어본·만들어본)
- [ ] 정렬 둘. **"만들어본 요리" 의 기본이 오래된 순**인가
- [ ] **+ 담기** → 날짜 고르는 창이 뜨고, 그날 담긴 메뉴와 메모가 같이 보이나
- [ ] **날짜는 나중에** 가 되나

### 장보기

- [ ] 담은 요리의 재료가 **BUY / CHECK / HAVE** 로 갈리나
- [ ] 칸 안에서 **매대**로 나뉘나
- [ ] 체크하면 **맨 아래로 내려가되 접히지 않나**
- [ ] 체크한 뒤 **칸이 안 바뀌나** (마트에서 어디까지 샀는지 놓치지 않게)
- [ ] 신호가 나쁠 때 체크가 **도로 풀리지 않나**
- [ ] **만든 메뉴의 재료가 빠지나** (공유 재료는 남아야 한다)

### 레시피 넣기 — **오늘 제일 안 재본 것**

지시서 4번은 **가짜 응답으로 배관만** 확인했다. 실제 캡처로는 아직이다.

- [ ] 캡처 1장 → 파싱 → 확인 화면 → 저장까지 가나
- [ ] 30초쯤 걸리는 동안 **"읽는 중" 이 바로 뜨나**
- [ ] 확인 화면의 근거(`evidence`)가 **한 번만** 나오나
- [ ] 저장 버튼을 두 번 눌러도 **한 건만** 생기나

여기서 실제 레시피가 쌓이면 **지시서 5번(미분류 확인)** 을 잴 수 있다 —
통과 기준은 미분류 10% 안쪽이다:

```sql
SELECT * FROM unmapped_term ORDER BY hit_count DESC;
```

### 앱 전체

- [ ] 탭을 오갈 때 **어제 것을 보여주지 않나** (`useFocusEffect`)
- [ ] 폰을 어두운 모드로 바꾸면 **앱도 따라오나**
- [ ] 아무거나 눌렀을 때 **눌리는 느낌**이 나나 (`Tap.tsx`)

### 아직 앱에 없는 것 — 없다고 탓하지 말 것

레시피 고치기 · 유튜브에서 찾기 · 안드로이드 공유 인텐트 · 영상에서 장면
뽑기 · 긴 캡처 자르기. 크기와 이유는 `CLAUDE.md` 의 표에 있다.

## 5. 아직 안 한 것

- **토큰 교체.** 지금 값이 대화 기록에 남아 있다. 자물쇠라 바꾸면 그만이지만
  (위 ⑤의 절차로), 그동안은 주소와 토큰을 아는 사람이 읽고 지울 수 있다
- **`development` 프로필 빌드.** 한 번 만들어두면 맥의 Metro 에 붙어서
  **저장할 때마다 폰에 반영**된다 — Expo Go 가 하려던 일을 우리 앱이 한다
- **실제 캡처로 파싱 재보기** (지시서 4번의 남은 절반)
- **미분류 확인** (지시서 5번)
- **`app.json` 의 `extra.eas.projectId` 등이 저장소에 없다.** `eas init` 이
  고친 것이 쓰는 사람 맥에만 있다 — 푸시되면 이 줄을 지운다
